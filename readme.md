# AutoPrime Concessionária

## Sobre o projeto

O AutoPrime é um site básico de uma concessionária de carros desenvolvido utilizando HTML5 e CSS3.

O projeto apresenta alguns veículos disponíveis para venda, contendo informações como ano, motorização, câmbio e preço. Também possui um vídeo do YouTube, área de contato e um menu de navegação.

## Tecnologias utilizadas

* HTML5
* CSS3
* YouTube
* Google Fonts e imagens externas

## Funcionalidades

* Página inicial com banner da concessionária
* Menu de navegação
* Exibição de veículos
* Fotos dos carros
* Informações sobre cada veículo
* Preços dos veículos
* Botão de interesse
* Vídeo incorporado do YouTube
* Área de contato
* Layout responsivo para dispositivos móveis

## Estrutura do projeto

```text
AutoPrime/
│
├── index.html
│
└── css/
    └── style.css
```

## Como executar

1. Baixe ou clone este projeto.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. O site será carregado automaticamente.

## Objetivo

O objetivo deste projeto é desenvolver uma página web simples para uma concessionária de veículos, colocando em prática conhecimentos de HTML e CSS, como estruturação de páginas, criação de cards, estilização, imagens, links, vídeos e responsividade.
